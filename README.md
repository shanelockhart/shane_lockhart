## Run locally

You will need Node.js and `pnpm` installed.

```bash
git clone https://github.com/shanelockhart/shane_lockhart.git
cd shane_lockhart
corepack enable
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Other available commands:

```bash
pnpm build
pnpm start
```

The main page is in `app/page.tsx`, site metadata is in `app/layout.tsx`, and styling is in `app/globals.css`.
